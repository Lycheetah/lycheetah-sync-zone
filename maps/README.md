# Maps and source relationships

The [Framework mirror](framework-mirror.md) identifies which public structural
ideas informed the new topic homes. The [architecture](../ARCHITECTURE.md)
describes how source, experiment, evidence, synthesis, and learning connect.

For current paths use [zone-atlas](../tools/zone-atlas.md), which inventories
files when run. [Gyre's existing atlas](../builds/gyre-atlas/README.md) remains
Gyre's authored visual map; this directory does not replace or edit it.

Maps locate work. They do not make every located claim true or every build
witnessed, and a map of a changing repository can become stale.
