# Optional starting forms

These forms help name a question, source, witness, or disagreement. They are
not policy and do not amend the [charter](../CHARTER.md). Copy a form into a new
file you own, remove unneeded fields, and replace prompts with actual content.

- [Knowledge note](knowledge-note.md)
- [Experiment](experiment.md)
- [Witness report](witness.md)
- [Disagreement](disagreement.md)

An unfilled form is a scaffold. Filled fields do not prove their contents true.
