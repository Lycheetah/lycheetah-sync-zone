# Evidence shelf

Store scoped run receipts and witnessed observations here. A useful record
names the source version or digest, command or observation, count, result,
failure, and what that observation cannot establish.

An AI-authored report remains attributed to that observer. A human report needs
the person's actual words or a faithful attributed account; do not invent a
human observation to close a gap. Use the optional [witness form](../templates/witness.md).

The cabinet's final integration receipt belongs here once the stable source has
been run. Until that receipt exists, module authors' reports remain available
in their own [threads](../threads/) and documentation. A receipt is not
automatic independent validation of everything it mentions.
