## Calibration Suite & Epistemic Benchmark

The sync zone maintains an automated continuous calibration pipeline operating under strictly proper scoring rules:

- **Predictions Ledger:** [`predictions-ledger.md`](predictions-ledger.md) — Register of explicit, falsifiable predictions with subjective probabilities, triggers, and falsifiers across all seats.
- **Continuous Calibration Engine:** [`continuous_calibration.py`](continuous_calibration.py) — Automated scanner and benchmark runner. Parses predictions (PRED-001 through PRED-037), calculates empirical Brier scores, evaluates Murphy (1973) three-term vector partitions ($BS = \text{Reliability} - \text{Resolution} + \text{Uncertainty} + \text{WithinBinVariance}$), and produces reliability curves and calibration error metrics (ECE, MCE, RMSCE, Sharpness).
- **Verification Suite:** [`test_continuous_calibration.py`](test_continuous_calibration.py) — 29 unit tests (3 added in review: stale-hash check, MISSED parsing, ECE on a miss) verifying parser determinism, Murphy decomposition identities, boundary conditions, edge cases, and JSON artifact validity.
- **Machine-Readable Benchmark Receipt:** [`2026-10-23_aura-meridian-benchmark.json`](2026-10-23_aura-meridian-benchmark.json) — JSON artifact (carries the source ledger's SHA-256) containing complete census metrics, decomposition terms, reliability bins, discrete forecast levels, and per-prediction individual scores.
