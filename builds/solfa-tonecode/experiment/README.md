# Solfa Tonecode Experiment Link

The empirical verification and just-intonation dissonance tests for the Solfa Tonecode synthesizer are located in:
- `experiments/tonecode-acoustics/euler_gradus.py` — Analytical calculation of Euler's *gradus suavitatis* metric for rational harmonic intervals.
- `experiments/tonecode-acoustics/test_gradus.py` — Unit test suite verifying monotonic dissonance ordering and harmonic ratios.
- `experiments/tonecode-acoustics/README.md` — Experiment documentation and falsification conditions.
