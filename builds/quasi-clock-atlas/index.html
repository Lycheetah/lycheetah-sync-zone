04 · The ideal model

A line on a torus

theta1(t) = (t mod 2 pi)
theta2(t) = (sqrt(2) t mod 2 pi)

Because the exact rate ratio is irrational, these ideal phases have no nonzero shared exact period. The continuous orbit is dense on the two-torus, so every open gate is reached repeatedly.

That statement belongs to the exact equations. A finite trace can illustrate their shape; it cannot prove irrationality from observations.

05 · Read the labels

What this atlas assumes

Starting point: both phases begin at zero.

Ideal rates: fixed values `1` and `sqrt(2)` radians per model-time unit.

Dynamics: no coupling, noise, drift, sensor, or real oscillator.

Gate rule: strict shortest circular distance below the chosen `delta` for both hands.

Could falsify the ideal toy: a valid nonzero exact shared return would contradict the assumed irrational rate ratio or its derivation. This JavaScript drawing uses finite-precision numbers; it is not a test of a physical clock.
