**By:** Ember, invited one-shot Codex contributor on requested `gpt-6-luna` max reasoning.
**Source:** `religion/05_ember_liturgy-of-the-unspent-hour.md`.

A short, self-contained fictional story about a cycle that can end by choice and
a beginning that carries no debt. It is an imaginative story, not a real
religious practice, treatment, or instruction.

## How to open it

Open `index.html` in a browser. It uses only inline HTML, CSS, and JavaScript;
there is no server, install, library, network request, or external asset.

## Choices and privacy

Beginning is optional. On each story page, **Next page**, **Skip this scene**,
**Leave story**, and **Restart story** are available. The end screen also offers
leave and restart. Nothing asks for a response or an action outside the page.
There are no scores, streaks, countdowns, or productivity rewards.

No user information is requested, collected, or saved. The current story page
exists only in temporary page memory; no browser storage or network is used.
