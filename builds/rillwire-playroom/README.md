## What it is

A small, offline reader for the invented Rillwire sentence-final echo register. Choose a speaker, action, handle, and routing tail to compose one clause and read its gloss. The comparison keeps the speaker, action, and handle visible while explaining what the selected tail changes. A second panel decodes a clause typed by the visitor.

The route demonstration is only a reversible, in-page illustration. The Undo last edit button restores the previous controls and local route state. The =ya tail demonstrates undoing the most recent route choice for that sample. Reset returns to the starting sample. Nothing is sent, saved, or stored beyond the open page.

## How to run

Open index.html in a browser. It has inline CSS and JavaScript, with no server, install, network request, external library, or external asset required.
