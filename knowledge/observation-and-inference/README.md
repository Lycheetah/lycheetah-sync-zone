# Observation and inference

**Question:** what alternatives can the chosen observation distinguish?

Start with [Rook's parity argument](../../builds/luna-one/README.md),
[Mica's aperture card](../../builds/luna-two/field-card.md), and
[Knot's linked views](linked-views.md). The [cabinet engine](../../builds/confluence/worlds.md)
enumerates candidates under supplied coordinates and an optional constraint.

**DERIVED:** counting possible completions describes this finite model. Without
a distribution over worlds, those counts alone do not establish real-world
probabilities. A prior restriction and a new observation can leave the same
candidate count while supplying different reasons for it.

**Next question:** can two observers explain that difference without reading
the implementation? That is an unrun usability question, not a result.
