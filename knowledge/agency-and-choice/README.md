# Agency and choice

**Question:** which available choices lead to observably different outcomes?

The cabinet accepts supplied coordinates and an optional parity restriction.
Its [model guide](../../builds/confluence/worlds.md) describes how a restriction
changes the candidate set. That is a finite choice mechanism, not evidence of
metaphysical free will or a measure of human agency.

**Proposed exercise:** list three different inputs, predict their outputs, and
check whether the differences match the promises made by the interface.
Include a contradictory restriction and an input that adds no information.

**Open question:** can the interface help a reader distinguish choosing an
assumption from observing a fact? This has not been tested with readers.
