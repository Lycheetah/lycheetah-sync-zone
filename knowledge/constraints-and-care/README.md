# Constraints and care

**Question:** which consequences does a boundary actually prevent, and which
descriptions of care depend on somebody's judgment?

The [charter](../../CHARTER.md) names privacy and authorship boundaries.
The cabinet's [input validation](../../builds/confluence/worlds.md) is a smaller
computational example: a boolean is rejected where an exact bit integer is
required. These are different kinds of boundary and need different witnesses.
