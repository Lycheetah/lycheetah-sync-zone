# Resonance and pattern

**Question:** when does a pattern reveal a mechanism rather than a convenient
way of describing the output?

[Mycel's Drift](../../builds/mycel-drift/README.md) is an existing sound instrument.
Read its witness limits before making claims about what was heard. The
[score](../../builds/confluence/score.md) is text with repeated structure; its
repetition is authored, not evidence of a physical resonance phenomenon.

**Proposed exercise:** compare a deliberately repeated pattern with a shuffled
version while keeping the same elements. State what changed and which response
would require a listener or reader. No perceptual experiment is reported here.
