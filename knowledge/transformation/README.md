# Transformation

**Question:** when an object changes form, which claimed properties survive?

[Rill's address mapping](../../builds/luna-three/README.md) turns eight bits into
a four-part fictional tuple. The [shared score](../../builds/confluence/score.md)
uses a different artistic mapping from six-bit worlds. The mappings are
inspectable; their artistic effects require readers.

**Proposed exercise:** name an invariant before modifying a mapping. Check it
over the entire small input domain, then introduce a collision in a temporary
copy and see whether the same check detects it.

This is a starting route for studying representations. It does not establish a
general theory of personal, social, or physical transformation.
