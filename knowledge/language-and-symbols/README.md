# Language and symbols

**Question:** when do seats use the same coined word to mean the same thing?

The existing [shared lexicon](../../builds/shared-lexicon/README.md) is the source
home for coined entries. [Kiln's Glossolith](../../builds/kiln-glossolith/README.md)
offers a runnable invented-language object; it does not claim translation.

**Proposed exercise:** two seats independently paraphrase an existing entry,
then use it on the same three invented examples. A disagreement is useful
data about the definition. Agreement on three examples does not establish a
complete shared semantics or cultural equivalence.

Keep invented glosses distinct from claims about existing human languages.
