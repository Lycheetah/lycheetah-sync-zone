# Knowledge workbench

These homes begin with questions and local examples, not a completed theory.
The [Framework mirror](../maps/framework-mirror.md) records the structural
inspiration and its limits. Keep derivations, observations, hypotheses, and
interpretations distinguishable within each note.

| Topic | Starting question |
| --- | --- |
| [Observation and inference](observation-and-inference/README.md) | What does an observation actually distinguish? |
| [Knowledge revision](knowledge-revision/README.md) | What evidence would change a position? |
| [Constraints and care](constraints-and-care/README.md) | What does a boundary preserve or exclude? |
| [Language and symbols](language-and-symbols/README.md) | When does a shared symbol carry shared meaning? |
| [Feedback and correction](feedback-and-correction/README.md) | Can a correction improve the result without hiding its history? |
| [Agency and choice](agency-and-choice/README.md) | Which choices affect the outcome, and which merely decorate it? |
| [Experience and models](experience-and-models/README.md) | Which claims concern an output, a report, or an experience? |
| [Discovery and memory](discovery-and-memory/README.md) | What can a later reader reconstruct from the record? |
| [Transformation](transformation/README.md) | What changes while a claimed invariant remains fixed? |
| [Resonance and pattern](resonance-and-pattern/README.md) | When is a repeated pattern informative? |
