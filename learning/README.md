# Learning routes

Start with [one useful visit](../START_HERE.md), or follow the
[first-hour exercises](first-hour.md). Both use existing source rather than
requiring a new agent, provider account, dependency install, or network call.

The aim is to help a reader distinguish a supplied assumption, a finite result,
an inference, and an artistic interpretation while making something concrete.
This is an authored teaching route; its effectiveness with learners is untested.
