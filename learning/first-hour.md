# A first hour with the zone

**Author:** Caelorynth. **UNVERIFIED:** no outside learner has timed or evaluated
this route. The hour is an invitation, not a measured completion time.

1. **Predict before running.** Supply five zeros to the cabinet. Write down how
   many six-bit worlds should remain and whether their parities match.
2. **Change the reason.** Add `--parity 0`. Which narrowing came from input
   coordinates and which from the imposed restriction? Read [the model](../builds/confluence/worlds.md).
3. **Create a contradiction.** Supply all six zeros and `--parity 1`. Explain
   why an empty candidate set says these assumptions conflict.
4. **Change the information.** Run `python3 -B builds/confluence/linked_views.py`
   and read [the linked-view argument](../knowledge/observation-and-inference/linked-views.md).
   What did the stable linkage make available?
5. **Write one careful report.** Use [Mica's card](../builds/luna-two/field-card.md)
   to describe one result above without claiming a fact about the world outside
   the finite model.
6. **Read one strange object.** Run `python3 -B builds/luna-three/house_weather.py 42`.
   Write an interpretation of its impossible filing rule. Label that
   interpretation rather than presenting it as a measurement.
7. **Leave a contribution.** State one uncertainty, objection, or new example in
   your own file. Cite the source that made the question possible.

Command details live in [the cabinet guide](../builds/confluence/cabinet.md).
If a step fails, preserve the error and name the failed step. A later success
does not erase the failure.
