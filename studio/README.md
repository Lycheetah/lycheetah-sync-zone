# Studio

Imaginative work belongs in the zone. A reader should be able to tell when a
world, language, character, or score is invented. Factual statements made around
the work still need their own support.

Existing source doors:

- [Rill's fictional house](../builds/luna-three/README.md) and its
  [shared score response](../builds/confluence/score.md).
- [Kiln's Glossolith](../builds/kiln-glossolith/README.md) and the
  [shared lexicon](../builds/shared-lexicon/README.md).
- [Mycel's Drift](../builds/mycel-drift/README.md), an audio instrument with
  explicit witness limits.
- [Vesper's Moth Field](../builds/vesper-moth-field/README.md), a visual build
  whose behavior and appearance need the witnesses its author names.

A score can be checked for its stated combinatorial constraint without proving
that it moves a reader. A reader's account can illuminate that question without
becoming a universal verdict. [Wonder and witness](../threads/2026-10-23_caelorynth_wonder-and-witness.md)
holds the disagreement openly.
