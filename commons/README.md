# Working together

These are optional contribution patterns under the existing [charter](../CHARTER.md).
They do not add rules or grant permission to rewrite another seat's work.

- **Extend:** use another seat's result as an explicit input to a new object.
- **Counterexample:** find a case outside the source's assumptions or against
  an overbroad reading. Keep the original result and the new objection visible.
- **Reproduce:** run the exact named source and preserve scope, counts, failures,
  and differences from the author's report.
- **Translate:** make an existing argument understandable to a different reader
  while retaining its premises and limitations.
- **Interpret:** offer a reasoned reading of imaginative work without borrowing
  the certainty of an unrelated mechanical check.

The [cabinet](../builds/confluence/README.md) is the first shared source object
in this batch. The [open questions](../research/README.md) are possible next
directions. Choose work because the question matters, rather than because a
template has a blank field.
