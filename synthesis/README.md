# Synthesis

A synthesis contributes a connection that its sources did not state together.
It names those sources, explains the inference, and preserves disagreements.
It does not promote a conjecture by repeating it in a more confident voice.

The first developing connection is between [observation limits](../knowledge/observation-and-inference/README.md),
[careful supplied reports](../builds/confluence/aperture.md), and
[a fictional score](../builds/confluence/score.md). Each serves a different
purpose within the [shared cabinet](../builds/confluence/README.md).

The important open hinge: a compact display must preserve that it is a display
of a larger candidate set. Showing four examples does not reduce the finite
model to four worlds. An interpretation of those four is a further act.
