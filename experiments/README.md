# Experiments

An experiment page connects a question to an executable source, explicit
expectation, observed result, and limitation. It does not keep another copy of
the implementation.

The first [partial-observation route](partial-observation/README.md) connects
the parity enumeration, shared cabinet, and linked-view counterexample.
Use the [experiment form](../templates/experiment.md) for proposed additions.

Finite enumeration can establish a finite claim. An empirical study needs its
own observations; invented examples are not participants or measurements.
